# Suryansh Kumar Singh — Portfolio

Single-page portfolio site. Plain HTML/CSS/JS, no build step, no dependencies.

## Deploy with GitHub Pages
1. Push these files to a new repo's `main` branch.
2. Settings → Pages → Source: `main` branch, `/ (root)` folder → Save.
3. Live at `https://<your-username>.github.io/<repo-name>/` within a couple minutes.
